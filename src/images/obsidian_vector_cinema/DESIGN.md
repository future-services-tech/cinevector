## Brand & Style

The visual identity fuses cinematic entertainment delivery with high-precision artificial intelligence analytics. The experience must feel immersive, technical, authoritative, and frictionless—evoking the backstage command console of a modern studio production house combined with an intelligent semantic discovery engine. 

The design aesthetic operates under **Cinematic Glassmorphism & Cybernetic Precision**:
- **Canvas Atmosphere:** Pure obsidian, deep space navy, and midnight slate foundations create a theatre-like immersion where media assets, vector embeddings, and glowing telemetry take visual precedence.
- **Accent Signals:** Hyper-focused strikes of electric cyan indicate computational intelligence, live states, and vector operations, balanced by radiant warm amber for critical curation, star ratings, and status highlights.
- **Glass & Structure:** Translucent frosted overlays, precise 1px micro-borders, and subtle specular lighting reflect state-of-the-art studio software. Interface elements stay structured and utilitarian without feeling sterile.

## Colors

The color architecture is built strictly for dark-mode immersion, using tonal obsidian steps to establish hierarchy and vibrant neon accents to guide user intent and indicate engine status.

### Foundation & Surfaces
- **Canvas Base (`#090D16`):** The absolute background for all platform surfaces, anchoring deep visual contrast.
- **Surface Elevation 1 (`#0F172A`):** Used for standard layout panels, persistent navigation bars, and base card structures.
- **Surface Elevation 2 (`#1E293B`):** Higher interactive surfaces, active cards, popovers, and hovered table rows.
- **Surface Muted / Glass (`rgba(15, 23, 42, 0.65)`):** Backdropped with blur filters for modals, overlays, and floating player bars.

### Primary Accents & States
- **Vector Cyan (`#06B6D4`):** The primary brand and action color. Denotes AI embeddings, active filter toggles, search vectors, primary calls to action, and interactive graph nodes.
- **Cinematic Gold (`#F59E0B`):** Secondary accent reserved for user curation ratings, critical system notices, awards tags, and featured badges.
- **Azure Pulse (`#3B82F6`):** Tertiary accent for link navigation, data streams, telemetry charts, and processing states.
- **System Borders (`rgba(255, 255, 255, 0.08)`):** Hairline precision borders defining visual containment across dark layers.

## Typography

The typography scale balances geometric presence with data-dense legibility:
- **Headlines (Plus Jakarta Sans):** Wide, geometric apertures project modern cinematic authority. Tighter letter spacing on large titles delivers a polished editorial presence suitable for studio title cards and metric dashboards.
- **Body & Data (Inter):** Highly legible neutral grotesque with tall x-height, engineered for vector logs, synopsis blurbs, data matrices, and media credits.
- **Labels & Microcopy:** Rendered with slightly enhanced tracking (`0.02em` to `0.05em`) in uppercase or semi-bold weights for badges, ratings tags, and metadata headers.

## Layout & Spacing

The interface employs a fluid, edge-conscious layout structured around a 12-column dynamic grid system with fixed gutters:
- **Desktop (1200px+):** 12 columns with `1.5rem` gutters and `2rem` screen margins. Layout preserves horizontal real estate for side-by-side video analytics, vector projections, and continuous horizontal film rails.
- **Tablet (768px - 1199px):** 8 columns with `1rem` gutters and `1.5rem` margins. Complex analytical panels collapse into vertical tabbed modules.
- **Mobile (<768px):** 4 columns with `1rem` gutters and `1rem` margins. Movie carousels convert to peek-edge scrollable swimlanes.

Spacing follows an intentional 4px/8px modular rhythm. Component padding scales cleanly from `space-xs` (tags and status dots) up to `space-xl` (section headers and hero container gutters).

## Elevation & Depth

Visual hierarchy operates through atmospheric tonal layering paired with controlled cyan and amber glows:
- **Level 0 (Canvas):** Pure `#090D16` base.
- **Level 1 (Panels & Rails):** `#0F172A` with a micro-border `rgba(255, 255, 255, 0.08)`. No cast shadow.
- **Level 2 (Cards & Media Tiles):** Translucent backdrop blur (`backdrop-filter: blur(16px)`), filled with `rgba(15, 23, 42, 0.75)`, framed with a 1px border `rgba(255, 255, 255, 0.1)`. In hover state, elevation is communicated not by heavy black drop shadows, but through a soft outer glow: `box-shadow: 0 0 24px -4px rgba(6, 182, 212, 0.25)`.
- **Level 3 (Modals & Overlays):** `#1E293B` combined with `0 20px 40px -10px rgba(0, 0, 0, 0.7)` and a perimeter ring of `rgba(6, 182, 212, 0.3)`.

## Shapes

The design system standardizes on **Rounded (Level 2)** shaping. 
- Base components (buttons, input fields, badges) use a base radius of `0.5rem` (8px).
- Structural media elements (video containers, analytical cards, modal viewports) step up to `1rem` (16px) via `rounded-lg`.
- Status pills, AI vector tag chips, and playback scrubbers retain continuous pill geometries (`rounded-full` / `9999px`) to create clear functional distinction against rigid card structures.

## Components

### Buttons
- **Primary Action:** Solid `#06B6D4` background, dark `#090D16` high-contrast text (`font-weight: 600`), `0.5rem` border radius. On hover, apply a subtle luminance shift and an ambient glow of `box-shadow: 0 0 16px rgba(6, 182, 212, 0.4)`.
- **Secondary / Studio:** `#1E293B` background with a crisp `rgba(255, 255, 255, 0.12)` border and white text. Active states highlight border with `#06B6D4`.
- **Ghost:** Borderless, neutral-400 text transitioning to cyan text on hover with background `rgba(6, 182, 212, 0.08)`.

### Chips & Badges
- **Vector Rating Badge:** Pill-shaped, background `rgba(245, 158, 11, 0.12)`, text `#F59E0B`, framed with 1px border `rgba(245, 158, 11, 0.3)`. Accompanied by a solid amber geometric star icon.
- **Engine Status Chip:** Pill-shaped, background `rgba(6, 182, 212, 0.1)`, text `#06B6D4`, with a pulsing 6px neon dot indicating live ingestion or vector compilation.

### Cards & Media Tiles
- Built with a 16:9 or 2:3 aspect ratio containment. Overlays use vertical gradient shading from `transparent` to `rgba(9, 13, 22, 0.95)`.
- Metadata (runtime, vector similarity score, genres) floats over the base in micro-typography with glass badge backing.

### Form Inputs & Query Fields
- Background set to `rgba(15, 23, 42, 0.8)` with a 1px border in `rgba(255, 255, 255, 0.1)`. 
- Focus state shifts the border to `#06B6D4` with an inner and outer cyan bloom: `box-shadow: 0 0 0 1px #06B6D4, 0 0 12px rgba(6, 182, 212, 0.25)`.
- Prefix icons for semantic and vector searches are locked to muted cyan (`#06B6D4` at 70% opacity).

### Checkboxes, Switches & Radio Controls
- Checkboxes: 18px rounded-sm boxes in `rgba(255, 255, 255, 0.08)`. Selected state fills with `#06B6D4` using an obsidian checkmark.
- Switches: Pill shape track in `#1E293B`; thumb is crisp white; active track glows cyan.
